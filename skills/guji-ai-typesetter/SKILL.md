# 古籍 AI 排版与预处理 Skill（`guji-ai-typesetter`）

本 Skill 用于在 **Codex / WorkBuddy / Claude Code / Gemini CLI** 等 Agent 环境下，自动化完成古籍文本的预处理、规范化标校与自动排版配置输出。

---

## 一、 核心标记语法规范（与 Web 重排工作台 100% 互通）

Agent 在处理古籍文本时，必须输出符合以下标记规范的文本：

| 标记语法 | 排版效果 | 使用场景 |
| :--- | :--- | :--- |
| `【注文内容】` | **双行小字夹注**（同列先右后左跨格折行） | 经传注疏、诗文自注、校勘按语、音义 |
| `〈专名〉` | **专名号**（左侧竖直单线） | 人名、地名、朝代、官职、年号 |
| `《书名》` | **书名号**（左侧竖直波浪线） | 典籍书名、篇名、诗题 |
| `[卷标:卷一]` | **换叶分卷**（自动另起新叶并更新版心卷次） | 卷首、篇章切换 |
| `[书耳:篇名]` | **书耳题记**（更新右上角书耳格内文字） | 篇名提示（2–4字为宜） |
| `[眉批:批语]` | **天头朱笔眉批**（对应列上方天头批注） | 评点、版本考证、提要 |
| `■` | **墨钉**（缺字/残泐占位黑块） | 文献残缺处 |
| `§` | **强制换半叶** | 序跋、目录后另起半叶 |

---

## 二、 Agent 自动化工作流

### 步骤 1：文本预处理与规范化（`preprocess_guji.py`）
当用户提供原始 TXT / Markdown / `chinese-poetry` JSON 文件时，先运行预处理脚本：
```bash
python3 skills/guji-ai-typesetter/scripts/preprocess_guji.py \
  --input raw_text.txt \
  --output normalized.txt \
  --judou \
  --auto-notes \
  --split-volumes
```
- `--judou`：将现代标点（`，；！？：`）规整为传统古籍句读（`、`、`。`），并剔除多余西文引号。
- `--auto-notes`：将文中的圆括号注释 `(按：...)`、`（注：...）`、`[注]...` 自动规范化为 `【...】` 双行夹注语法。
- `--split-volumes`：自动识别 `卷一`、`卷上`、`第X章`、`第X回` 等标题行，前置 `[卷标:...]` 与 `[书耳:...]`。

### 步骤 2：AI 深度标校（由 Agent 或自定义大模型 API 完成）
在预处理文本基础上，Agent 应依据古籍整理规范执行以下精校：
1. **正文与注疏分离**：若原文夹杂未加括号的“注曰：”、“按：”、“疏曰：”、“音义：”等段落，将其用 `【...】` 包裹，确保排版时自动降号为双行小字。
2. **专名与书名标校**：识别人名、地名、朝代并包裹 `〈...〉`，识别典籍篇名并包裹 `《...》`。
3. **提要与眉批**：在每卷开端添加 `[眉批:...]` 提炼本卷主旨或版本特征。

### 步骤 3：Agent 控制下的自动排版与工程生成（`auto_typeset.py`）
调用自动排版脚本，根据文本体裁自动匹配最佳历代刻本版式参数（如经史注疏用宋刻本 9×18、白文大字用江户魁本 7×14、四库风格用朱丝栏 8×20），生成统计报告与 `.guji.json` 工程文件：
```bash
python3 skills/guji-ai-typesetter/scripts/auto_typeset.py \
  --input normalized.txt \
  --title "论语集注" \
  --author "〔宋〕朱熹集注" \
  --genre "jing_zhushu" \
  --output-json output/lunyu.guji.json
```
生成的 `.guji.json` 工程文件可直接拖入「芸窗·古籍 AI 排版系统」Web 工作台，一键预览全书筒子页并导出整书 PDF。

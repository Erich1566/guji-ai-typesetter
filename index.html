🤖 配套 Agent Skill（Codex / WorkBuddy / CLI 调用指南）

项目仓库内置 skills/guji-ai-typesetter/ 技能包，支持外部 Agent 自动完成古籍文本规范化与排版工程生成。

# 1. 文本预处理与规范化 (preprocess_guji.py)
python3 skills/guji-ai-typesetter/scripts/preprocess_guji.py \
  --input raw.txt \
  --output normalized.txt \
  --judou --auto-notes --split-volumes
# 2. Agent 控制自动排版生成工程 (auto_typeset.py)
python3 skills/guji-ai-typesetter/scripts/auto_typeset.py \
  --input normalized.txt \
  --title "论语集注" --genre jing_zhushu \
  --output-json lunyu.guji.json

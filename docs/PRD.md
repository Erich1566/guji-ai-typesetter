# 芸窗·古籍 AI 排版系统 — 产品需求文档（PRD）

## 1. 项目愿景与定位
打造一套**零后端依赖、纯静态可部署于 GitHub Pages、同时支持人类可视化精排与 AI Agent 自动化调用**的古籍雕版重排工作台（`Guji AI Typesetter`）。系统兼顾传统雕版美学（筒子页、双行夹注、鱼尾象鼻版心、书耳、朱笔句读、专名/书名线、线装封面与牌记）与现代 AI 赋能（自定义大模型 API 标校、殆知阁/中华古诗词底层语料库直连、多格式文档导入、配套 Agent Skill 规范化预处理与自动化排版）。

---

## 2. 竞品对标与差异化优势
| 维度 | 传统工具（如 `vRain` Perl/Python CLI） | 商业古籍阅读平台 | **芸窗·古籍 AI 排版系统（本项目）** |
| :--- | :--- | :--- | :--- |
| **运行门槛** | 需配置 Perl/LaTeX/本地字库环境 | 闭源、无法自定义文本与版式 | **纯静态 HTML/JS，打开浏览器即用，支持 GitHub Pages** |
| **底层语料** | 需用户自行搜集整理文本 | 仅限站内既有书目 | **内建殆知阁 + Chinese-Poetry 直连检索，一键载入重排** |
| **AI 标校能力** | 无（纯规则替换） | 无或封闭 | **支持自定义 OpenAI 兼容 API（DeepSeek/Qwen/OpenAI/Ollama）** |
| **Agent 生态** | 无标准化 Skill 接口 | 无 | **配套标准 `SKILL.md` 与 Python CLI，供 Codex/WorkBuddy 等 Agent 调用** |
| **字体支持** | 依赖系统本地字体 | 固定内置字体 | **内置 7 款免费开源古籍字体 + 本地 TTF/OTF/WOFF2 直传** |
| **交付导出** | 仅命令行生成 PDF | 仅在线阅读或付费下载 | **单叶高清 PNG、整书多卷合订 PDF（含封面与牌记）、重排源码** |

---

## 3. 核心功能需求（Functional Requirements）

### 3.1 底层语料库直连模块（Corpus Hub）
1. **殆知阁古代文献库直连（`garychowcmu/daizhigev20`）**
   - 通过 GitHub REST API 动态浏览十大部类：`儒藏`、`史藏`、`子藏`、`集藏`、`诗藏`、`易藏`、`医藏`、`艺藏`、`道藏`、`佛藏`。
   - 支持目录树钻取、书名关键词过滤，并通过 `raw.githubusercontent.com` / `cdn.jsdelivr.net` 拉取原文 TXT（自动处理大文件分段载入与编码）。
2. **中华古诗词数据库直连（`chinese-poetry/chinese-poetry`）**
   - 预置核心典籍快捷入口：《全唐诗》、《宋词》、《诗经》、《楚辞》、《论语》、《四书五经》、《元曲》、《曹操诗集》、《纳兰性德》。
   - 自动解析 JSON 数组结构（`title`、`author`、`paragraphs`/`content`），一键转换为符合古籍排版规范的竖排文本并自动附加`〈专名〉`与`[卷标:...]`。

### 3.2 多源文档上传与预处理（Document Ingestion）
- 支持拖拽或选择上传本地文档：`.txt`、`.md`、`.json`（支持 `chinese-poetry` 格式）、`.html`、`.docx`（通过浏览器端 `mammoth.js` 解析提取纯文本与段落结构）。
- 内置文本处理工具：繁简转换（简→繁）、现代标点转传统句读（`。`、`、`）、一键去句读还原白文刻本。

### 3.3 自定义 AI API 与智能标校引擎（AI Typesetting Engine）
- **API 配置面板（本地持久化 `localStorage`）**：
  - 支持任意 OpenAI 兼容接口：`Base URL`（预设 OpenAI、DeepSeek、通义千问、智谱 GLM、本地 Ollama）、`API Key`、`Model Name`、`Temperature`。
- **四大 AI 一键工作流**：
  1. **AI 正文与注疏分离**：自动识别古籍中的注文、按语、校勘记，转换为 `【双行夹注】` 语法。
  2. **AI 专名与句读精校**：自动添加 `〈人名/地名/朝代〉` 专名号、`《书名/篇名》` 书名号，并将现代标点规范化为古籍句读。
  3. **AI 智能分卷与眉批生成**：为长文自动切分 `[卷标:卷X]`、`[书耳:篇名]`，并生成提纲挈领的 `[眉批:...]`。
  4. **AI 版式参数推荐**：根据文本体裁（经部注疏、诗集、史传、笔记）自动推荐并应用最佳刻本参数（半叶行数、每行字数、边栏、丝栏、鱼尾、纸张）。

### 3.4 雕版重排与封面定制引擎（Core Typesetting & Binding）
- **字格级竖排左行渲染**：支持 6–13 行 × 12–24 字自由调节，双行小字支持「传统先右后左跨格折行」与「逐格并列」。
- **内置免费开源古籍字体 + 本地字体**：
  - 内置 7 款免费商用/开源字体（思源宋体简/繁、霞鹜文楷繁/屏显版、Shippori Mincho 刻本明朝、志莽行书、马善政楷书）。
  - 支持本地 `.ttf` / `.otf` / `.woff2` 文件上传及浏览器系统字体扫描。
- **线装书衣与牌记定制**：可调绢锦底色、四眼/六眼/包背装订、题签位置/底色/边框、书名副题落款及扉页木记牌记。
- **整书多卷排版与导出**：支持「整书平铺总览」、单叶高清 PNG 导出、整书一键导出 PDF（含自定义封面+牌记+全书正文）。

### 3.5 配套 Agent Skill 规范包（`skills/guji-ai-typesetter/`）
- 面向 **Codex、WorkBuddy、Claude Code、Gemini CLI** 等 Agent 打造标准化 Skill：
  - `SKILL.md`：定义古籍预处理规范、标记语法标准（`【】`、`〈〉`、`《》`、`[卷标:]`、`[书耳:]`、`[眉批:]`）、Agent 自动化排版调用流程。
  - `scripts/preprocess_guji.py`：命令行文本清洗、简繁转换、注疏括号规范化、现代标点转句读、自动分卷脚本。
  - `scripts/auto_typeset.py`：支持直接读取处理后的古籍文本或 JSON 语料，生成可直接导入 Web 工作台的 `.guji.json` / `.txt` 工程文件或调用本地 Chromium 批量输出 PDF。

---

## 4. 非功能性需求
- **纯静态与隐私安全**：API Key 仅保存在用户浏览器本地 `localStorage`，不经过任何第三方中转服务器；所有排版计算与 PDF 合成均在本地完成。
- **响应式与印刷级输出**：兼容桌面端双栏工作台与平板/窄屏视图，导出 PDF 分辨率满足 2x Retina 清晰度。
